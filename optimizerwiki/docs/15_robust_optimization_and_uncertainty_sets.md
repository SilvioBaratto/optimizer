> [!abstract] Summary
> The chapter shows how robust optimization responds to estimation error by transforming the uncertain data of a mathematical program into an uncertainty set and optimizing with respect to the worst case. It establishes that the robust counterpart of a linear constraint with ellipsoidal uncertainty is a second-order cone constraint, so that the robust problem remains solvable as a conic program, and applies the paradigm to portfolio selection: a separable uncertainty model on expected returns and covariance generates a robust efficient frontier and a worst-case portfolio expressible in conic form. The result is that robustness replaces the fragility of mean-variance weights with a solution that incorporates the uncertainty of the estimated parameters.

## From Nominal Fragility to Robustness

Mean-variance analysis constructs efficient portfolios starting from an estimate of the model's parameters, that is, from the vector of expected returns and the covariance matrix of asset returns. In practice these parameters are estimated with error, and mean-variance analysis is often sensitive to that error: an efficient portfolio calculated with one estimate of the parameters can give very poor results for another set of parameters, similar and statistically hard to distinguish from the one assumed [KimBoyd2007]. This is the same fragility documented in the chapter [[08 Errore di stima, outlier e shrinkage]]: the nominal solution — the one obtained by treating the estimates as if they were the true values — is not protected against the fact that the true values differ from them.

The nature of the problem can already be grasped at the level of a generic linear program with uncertain data. Consider the program
$$\min\{c^T x \mid Ax \ge b\},$$
whose data $A,b$ are uncertain to a greater or lesser degree in almost all real problems [BenTalNemirovski1999]. The classical approach ignores the uncertainty and uses a representative nominal value of the data. The point is that there are situations in which an applicable solution must remain feasible for all realizations of the data, and not even a small constraint violation can be tolerated: in engineering structural design, for example, even small variations in the acting forces can cause violent displacements and make the structure strongly unstable [BenTalNemirovski1999]. To this end Ben-Tal and Nemirovski distinguish "hard" constraints, which must be satisfied whatever the realization of the data, from "soft" constraints, which admit a violation with a penalty or with a certain probability as in stochastic programming. Robust optimization deals with the uncertainty associated with hard constraints.

The fragility of the nominal solution has a precise manifestation: the optimal solution of the nominal problem can become infeasible, or perform very poorly, under a perturbation of the coefficients. This is the motivation that, in the chapter, optimization converts into a constructive response.

## The Robust Counterpart of an Uncertain Linear Program

The robust paradigm replaces the uncertainty on the data with a prescribed uncertainty set $\mathcal U$, of which the matrix $A$ is a member, and requires that the solution remain feasible for every realization of the data in that set. The feasibility of a vector $x$ is thus interpreted as
$$Ax \ge b \quad \forall (A,b)\in\mathcal U,$$
and the associated robust problem is
$$\min\{c^T x \mid Ax \ge b \ \ \forall (A,b)\in\mathcal U\}. \tag{RC}$$
Ben-Tal and Nemirovski call (RC) the *robust counterpart* of the uncertain problem and call *robust solution* a vector $x^*$ that solves it [BenTalNemirovski1999]. A vector feasible for (RC) is called *robust feasible*: it simultaneously satisfies all the realizations of the constraints drawn from $\mathcal U$; a robust feasible solution with the best possible objective value is called *robust optimal*. Since no stochastic model of the data is assumed, the approach is worst-case oriented: the requirement of feasibility for every realization is equivalent to optimizing against the worst feasible realization of the constraints.

For convenience the problem can be posed in the form
$$(P)\qquad \min\{c^T x \mid Ax \ge 0, \ f^T x = 1\},$$
in which $c$ and $f$ are fixed data and the uncertainty concerns only the matrix $A\in\mathcal U$; the robust counterpart becomes
$$(P_{\mathcal U})\qquad \min\{c^T x \mid Ax \ge 0 \ \ \forall A\in\mathcal U, \ f^T x = 1\}. \tag{$P_{\mathcal U}$}$$
The robust counterpart does not change if $\mathcal U$ is replaced with its closed convex hull; one can therefore assume $\mathcal U$ convex and closed [BenTalNemirovski1999]. The problem $(P_{\mathcal U})$ has a continuum of constraints — one for each $A\in\mathcal U$ — and is thus a semi-infinite problem, which at first sight appears intractable: the crucial question is for which geometries of $\mathcal U$ it admits an explicit and solvable form.

A first example shows that there can be a gap between the solvability properties of instances of an uncertain linear program and those of its robust counterpart. Consider
$$\min\ x_1+x_2 \quad\text{s.t.}\quad \begin{cases} a_{11}x_1 + x_2 \ge 1\\ x_1 + a_{22}x_2 \ge 1\\ x_1 + x_2 = 1\\ x_1,\,x_2 \ge 0,\end{cases}$$
with uncertain elements $a_{11},a_{22}$ and uncertainty set $\mathcal U = \{a_{11}+a_{22}=2,\ \tfrac12\le a_{11}\le\tfrac32\}$. Every instance is clearly solvable with optimal value $1$ (if $a_{11}\ge 1$ the solution is $(1,0)$, otherwise $(0,1)$), while the robust counterpart, which coincides with
$$\min\ x_1+x_2 \quad\text{s.t.}\quad \begin{cases} \tfrac12 x_1 + x_2 \ge 1\\ x_1 + \tfrac12 x_2 \ge 1\\ x_1 + x_2 = 1\\ x_1,\,x_2 \ge 0,\end{cases}$$
is infeasible [BenTalNemirovski1999]. The gap closes under natural assumptions. Let $\mathcal U_i$ be the projection of $\mathcal U$ onto the set of data of the $i$-th constraint. The uncertainty is said to be *constraint-wise* if $\mathcal U$ is the direct product of the projections,
$$\mathcal U = \mathcal U_1 \times \mathcal U_2 \times \cdots \times \mathcal U_m,$$
that is, when the robust counterpart "perceives" only the possible realizations of the single constraint and not the dependencies between distinct constraints. Under the *Boundedness Assumption* — the existence of a compact convex set $Q$ that certainly contains the feasible sets of all instances — the following proposition holds [BenTalNemirovski1999]: if the uncertainty is constraint-wise and the Boundedness Assumption is verified, then $(P_{\mathcal U})$ is infeasible if and only if there is an infeasible instance, and if $(P_{\mathcal U})$ is feasible with optimal value $c^*$ then
$$c^* = \sup\{c^*(P)\mid (P)\in\mathcal P\},$$
where $\mathcal P$ is the family of instances. Under these assumptions, the robust counterpart is thus no worse than the "worst" instance.

## Box and Ellipsoidal Sets and Tractability

The choice of the geometry of the uncertainty set jointly determines the degree of conservatism and the tractability of the robust counterpart. The case of *column-wise* uncertainty, studied by Soyster, assumes that the columns $a_i$ of the constraint matrix $Ax\le b$, $x\ge 0$, are known to belong to convex sets $K_i$, and requires
$$\textstyle\sum_{i=1}^n x_i a_i \le b \quad \forall\,(a_i\in K_i,\ i=1,\dots,n).$$
This system is equivalent to a system of linear constraints
$$A^* x \le b,\quad x\ge 0,\qquad a^*_{ij} = \sup_{a_i\in K_i}(a_i)_j,$$
in which every element of the matrix simultaneously assumes the least favorable value [Soyster1973]. This equivalence to a linear system is specific to column-wise uncertainty and is extremely conservative. The general case is the *row-wise* one, in which the uncertainty sets concern the rows of the matrix: here the robust counterpart is typically not a linear program, but is able to reflect the fact that generically the coefficients cannot simultaneously assume their worst values [BenTalNemirovski1999].

The box, or interval, uncertainty set corresponds to fixing a range of variation for each coefficient. For modeling real uncertainty it is, however, as simple as it is rigid, and Ben-Tal and Nemirovski propose as a reasonable compromise between flexibility and tractability *ellipsoidal* uncertainty, that is, a set given by the intersection of a finite number of ellipsoids, i.e., of sets defined by convex quadratic inequalities. The reasons are that ellipsoidal sets form a relatively broad family — which includes polytopes and allows good approximation of many complicated convex sets — that an ellipsoid is parametrically specified by data of moderate dimension, that in some cases there are statistical reasons giving rise to ellipsoidal uncertainty, and above all that the robust counterpart associated with an ellipsoidal $\mathcal U$ possesses a particularly favorable analytical structure [BenTalNemirovski1999].

This last point is the central tractability result. A quadratic cone program (CQP) is a program with a linear objective and constraints of the type
$$a_i^T x + \alpha_i \ge \lVert B_i x + b_i\rVert,\qquad i=1,\dots,M,$$
where $\alpha_i$ are fixed reals, $a_i,b_i$ fixed vectors, $B_i$ fixed matrices, and $\lVert\cdot\rVert$ is the Euclidean norm. That the robust counterpart of a linear constraint with ellipsoidal uncertainty is precisely a constraint of this type can be seen in the simplest case, in which $\mathcal U$ is an ordinary ellipsoid
$$\mathcal U = \{A = P^0 + \textstyle\sum_{j=1}^k u_j P^j \mid u^T u \le 1\}.$$
Letting $R_i$ be the matrix whose columns are the $i$-th rows of $P^1,\dots,P^k$, the $i$-th row of $A$ is $r_i^{(0)} + R_i u$, and $x$ (with $f^T x = 1$) is robust feasible if and only if, for every $i$,
$$[r_i^{(0)}]^T x + (R_i u)^T x \ge 0 \quad \forall\,\lVert u\rVert\le 1.$$
The minimum of the left-hand side with respect to $u$ in the unit ball is computed via Cauchy-Schwarz:
$$\min_{\lVert u\rVert\le 1}\big([r_i^{(0)}]^T x + u^T R_i^T x\big) = [r_i^{(0)}]^T x - \lVert R_i^T x\rVert,$$
so that the robust feasibility condition becomes $[r_i^{(0)}]^T x \ge \lVert R_i^T x\rVert$, and $(P_{\mathcal U})$ is exactly the CQP
$$\min\{c^T x \mid [r_i^{(0)}]^T x \ge \lVert R_i^T x\rVert,\ i=1,\dots,m;\ f^T x = 1\} \tag{16}$$
[BenTalNemirovski1999]. The result holds in general: the robust counterpart $(P_{\mathcal U})$ of an uncertain linear program with general ellipsoidal uncertainty converts into a quadratic cone program. Quadratic cone programs are solvable with interior-point methods in polynomial time, with computational complexity essentially equal to that of linear programs of comparable size [BenTalNemirovski1999]. Polytopic uncertainty also falls within this framework: a polytope, being the intersection of "slabs" $\{u\mid s_i\le d_i^T u\le r_i\}$ and each slab being an ellipsoidal cylinder, is itself an ellipsoidal uncertainty, and the corresponding robust counterpart reduces to a linear program. This is the tractability that makes the robust paradigm operational: the semi-infinite requirement of feasibility for every realization compacts into a finite number of conic constraints. The notions of the second-order cone and of conic programming on which this reduction rests are developed in the chapter [[14 Ottimizzazione convessa - coni, dualità e KKT]].

## The Single-Period Portfolio Problem

Ben-Tal and Nemirovski illustrate the entire paradigm on a simple portfolio problem. One unit of capital is invested at the beginning of the year in a portfolio of $n$ assets; the return per unit invested in asset $i$ is $p_i > 0$, and one wants to determine the fraction $x_i$ to invest in asset $i$ so as to maximize the year-end value $\sum_i p_i x_i$. When the returns $p_i$ are known in advance, the problem is the linear program
$$\max\Big\{\textstyle\sum_{i=1}^n p_i x_i \ \Big|\ \sum_{i=1}^n x_i = 1,\ x_i\ge 0\Big\}, \tag{19}$$
whose solution is obvious: invest everything in the "most promising" asset, the one with the largest $p_i$. Ordering $p_1<p_2<\cdots<p_n$, the solution is $x_n = 1$, $x_i = 0$ for $i<n$.

This nominal solution is fragile. Suppose now the $p_i$ are uncertain: the nominal values $p_i^*$ are known, with $p_1^*<\cdots<p_n^*$, and bounds $\sigma_i$ such that the actual values fall in the intervals $\Delta_i = [p_i^*-\sigma_i,\ p_i^*+\sigma_i]$, with the $p_i$ mutually independent and symmetrically distributed around $p_i^*$. The simplest stochastic reformulation — maximizing the expected value — coincides with the nominal program $(19)$ with the $p_i^*$ in place of the $p_i$: the nominal solution again invests everything in the most promising asset $n$, producing a random return with expected value $\mathcal E\{x^{\text{nom}}\} = p_n^*$.

The robust counterpart approach instead starts from the specification of the uncertainty set. The most immediate choice is the box $B = \{p \mid |p_i - p_i^*|\le\sigma_i\ \forall i\}$, that is, Soyster's approach; the corresponding robust policy consists in investing everything in the assets with the highest worst-case return $p_i^*-\sigma_i$, and is too conservative to be of real interest [BenTalNemirovski1999]. Applying the robust counterpart, however, one is not obliged to include in the uncertainty set everything that can happen. Ben-Tal and Nemirovski propose for the uncertain coefficients the ellipsoidal set
$$\mathcal U^\theta = \Big\{p\in\mathbb R^n \ \Big|\ \textstyle\sum_{i=1}^n \sigma_i^{-2}(p_i - p_i^*)^2 \le \theta^2\Big\}.$$
The parameter $\theta$ is a subjective value reflecting the decision maker's attitude toward risk: the larger $\theta$, the more risk-averse the decision maker. For $\theta=0$, $\mathcal U^0$ reduces to the singleton $\{p^*\}$ of the nominal data; for $\theta=1$, $\mathcal U^1$ is the ellipsoid of maximum volume contained in the box $B$; for $\theta=\sqrt n$, $\mathcal U^\theta$ is the ellipsoid of minimum volume containing the box.

## The Robust Counterpart as a Markowitz-Style Program

Writing the program $(19)$ in the equivalent form $\max\{y \mid y\le\sum_i p_i x_i,\ \sum_i x_i = 1,\ x\ge 0\}$ and applying the result on ellipsoidal uncertainty, one obtains the robust counterpart with respect to $\mathcal U^\theta$:
$$\max\Big\{\textstyle\sum_{i=1}^n p_i^* x_i - \theta\, V^{1/2}(x) \ \Big|\ \sum_{i=1}^n x_i = 1,\ x\ge 0\Big\},\qquad V(x) = \sum_{i=1}^n \sigma_i^2 x_i^2. \tag{22}$$
The problem $(22)$ closely resembles Markowitz's approach to portfolio selection, with the difference that in that classical approach the role of $V^{1/2}(x)$ is played by $V(x)$ [BenTalNemirovski1999; Markowitz1952]. The term $-\theta V^{1/2}(x)$ penalizes allocations for which the uncertainty of returns translates into a large possible deviation of the final value.

The robust counterpart $(22)$ is justified by a direct argument about the randomness of the return. Distributing the unit of capital as $x=(x_1,\dots,x_n)$, the return $y=\sum_i p_i x_i$ can be written as
$$y = \sum_{i=1}^n p_i^* x_i + \zeta,\qquad \zeta = \sum_{i=1}^n x_i(p_i - p_i^*),$$
where the random part $\zeta$ has zero mean and variance
$$\operatorname{Var}(\zeta) = \sum_{i=1}^n x_i^2\, \mathcal E\{(p_i - p_i^*)^2\} \le \sum_{i=1}^n x_i^2 \sigma_i^2 = V(x).$$
The "typical" value of $y$ therefore differs from the nominal value $\sum_i p_i^* x_i$ by a quantity of order $V^{1/2}(x)$. The idea for handling the uncertainty is to choose a reliability level $\theta$, ignore the events in which the noise $\zeta$ is less than $-\theta V^{1/2}(x)$, and among the remaining events take the worst one — $\zeta = -\theta V^{1/2}(x)$ — acting as if it were the only possible one. The "stable" return of a decision $x$ is then $\sum_i p_i^* x_i - \theta V^{1/2}(x)$, which is precisely the objective of $(22)$ [BenTalNemirovski1999]. It should be stressed that the uncertainty ellipsoid $\mathcal U^\theta$ is not in any sense an approximation of the support of the distribution of $p$: for large $\theta$ and $n$ not too small, the ellipsoid may contain no realization of the random vector $p$ at all; for example, with $\theta=6$ and $n>36$ the ellipsoid $\mathcal U^6$ contains no realization. The decision maker can solve the robust counterparts for different values of $\theta$ and choose the one that in their judgment gives the best compromise between "safety" and "greed."

A numerical example makes the stability gain concrete. With $n=150$, nominal coefficients in arithmetic progression $p_i^* = \lambda^* + i\delta$ with $\lambda^*=1{,}15$ and $\delta = 0{,}05/150$, and increasing deviations $\sigma_i = \tfrac13\delta\sqrt{2in(n+1)}\approx 0{,}0236\sqrt i$ (the most promising assets are also the riskiest), three policies are compared: the nominal policy $\mathcal N$, the solution of the nominal program, which invests everything in the most promising asset; the robust policy $\mathcal{RC}$, the solution of $(22)$ with $\theta=1{,}5$, which for this choice of the $\sigma_i$ invests equally in all assets, $x_i = 1/n$, with robust optimal value $1{,}15$; and the robust policy $\mathcal{MVZ}$ of Mulvey, Vanderbei, and Zenios [MulveyVanderbeiZenios1995], based on a penalty function for the violation of the uncertain constraint along a set of scenarios. Over $400\times 9 = 3\,600$ simulations, the $\mathcal{RC}$ policy turns out to be about $15$ times more stable than the nominal one in terms of the standard deviation of the return and never produces losses (always yielding at least $11\%$ profit), while the nominal policy, with probability $0{,}5$, suffers a $9\%$ loss of capital; the stability of $\mathcal{MVZ}$ depends strongly on the number of scenarios and remains lower than that of $\mathcal{RC}$ [BenTalNemirovski1999]. The robust policy implements the principle of not concentrating everything in a single asset.

## The Separable Uncertainty Model for Mean-Variance

The passage from the single-period example to the full mean-variance analysis is carried out by Kim and Boyd, who explicitly incorporate a model of uncertainty on the parameters and conduct the analysis for the worst-case scenario [KimBoyd2007]. Consider $n$ risky assets with returns described by a random vector $a\in\mathbb R^n$ with mean $\mu = \mathbb E\,a$ and covariance $\Sigma = \mathbb E\,(a-\mu)(a-\mu)^T$, with $\Sigma$ positive definite. A portfolio $w=(w_1,\dots,w_n)$ has mean return $w^T\mu$ and risk, measured by the standard deviation, $(w^T\Sigma w)^{1/2}$; the portfolio must belong to a closed convex subset $\mathcal W$ of $\mathbb R^n$ and satisfy the budget constraint $\mathbf 1^T w = 1$. The convex set $\mathcal W$ can represent a wide range of allocation constraints, including diversification constraints, long/short constraints, market impact constraints with convex costs, convex transaction costs, and limit constraints. The nominal efficient frontier is the trajectory of the solution of the problem
$$\max\ w^T\mu \quad\text{s.t.}\quad w\in\mathcal W,\ \sqrt{w^T\Sigma w}\le\sigma,$$
as the acceptable volatility level $\sigma$ varies, and defines the increasing concave curve $f_{\mu,\Sigma}(\sigma) = \sup_{w\in\mathcal W,\ \sqrt{w^T\Sigma w}\le\sigma} w^T\mu$; the notions of efficient frontier and mean-variance efficient portfolio are those established in the chapter [[02 Selezione media-varianza]] starting from [Markowitz1952].

The uncertainty is described by a product-form, or *separable*, model,
$$\mathcal U = \mathcal M \times \mathcal S \subseteq \mathbb R^n \times \mathbb S^n_{++},$$
where $\mathcal M$ is the set of possible expected return vectors and $\mathcal S$ the set of possible covariances, with $\mathbb S^n_{++}$ the set of symmetric positive definite $n\times n$ matrices. In this model the uncertainties on the mean vector and on the covariance are independent of each other; $\mathcal M$ and $\mathcal S$ are assumed to be compact. With model uncertainty, the performance of a portfolio $w$ is described by the set of risk-return pairs computed as the parameters in $\mathcal U$ vary,
$$\mathcal P(w) = \big\{\big((w^T\Sigma w)^{1/2},\ w^T\mu\big) \ \big|\ (\mu,\Sigma)\in\mathcal U\big\},$$
which for connected $\mathcal U$ is a rectangle (box). The worst-case scenario is located in the bottom-right corner of this box, the one with the highest risk and the lowest return. This defines the worst-case risk and the worst-case return of $w$:
$$\sigma_{\text{wc}}(w) = \sup_{\Sigma\in\mathcal S}\sqrt{w^T\Sigma w},\qquad r_{\text{wc}}(w) = \inf_{\mu\in\mathcal M} w^T\mu.$$
The notion of portfolio preference extends to robust analysis with a separable model: a portfolio $\bar w$ is preferred to $\hat w$ if $\bar w$ has worst-case risk less than or equal to and worst-case return greater than or equal to those of $\hat w$ [KimBoyd2007]. Computing these extremes, when $\mathcal M$ and $\mathcal S$ are convex, requires minimizing or maximizing a linear function over a convex set, and the four corners of the box $\mathcal P(w)$ can therefore be computed efficiently.

## The Robust Efficient Frontier

The extension of the efficient frontier to the worst-case scenario is the robust counterpart of the mean-variance problem. Consider
$$\max\ r_{\text{wc}}(w)\quad\text{s.t.}\quad w\in\mathcal W,\ \sigma_{\text{wc}}(w)\le\sigma, \tag{9}$$
that is, one seeks the portfolio that maximizes the worst-case expected return subject to a maximum acceptable level of worst-case volatility. The trajectory of the solution as $\sigma$ varies defines the *robust efficient frontier*
$$f_{\text{rob}}(\sigma) = \sup_{w\in\mathcal W,\ \sigma_{\text{wc}}(w)\le\sigma} r_{\text{wc}}(w),$$
an increasing concave curve for $\sigma\ge\sigma_{\text{inf}}$, where $\sigma_{\text{inf}} = \inf_{w\in\mathcal W}\sigma_{\text{wc}}(w)$ is the minimum worst-case risk. A feasible portfolio is called *robust MV efficient* if its worst-case risk and return lie on the strictly increasing portion of $f_{\text{rob}}$; any portfolio with the same worst-case return would have a larger worst-case risk [KimBoyd2007]. The objective of $(9)$ is a concave function of $w$, being the pointwise infimum of a family of linear functions, and the constraint set is convex, being the intersection of a family of convex quadratic constraints parameterized by $\Sigma\in\mathcal S$ with the convex allocation constraint $w\in\mathcal W$; the problem $(9)$ is thus a semi-infinite convex program.

A fundamental link connects the robust frontier to the efficient frontiers compatible with the assumptions on the parameters. For any $\mathcal M\subseteq\mathbb R^n$ and $\mathcal S\subseteq\mathbb S^n_{++}$,
$$f_{\text{rob}}(\sigma) \le \inf_{\mu\in\mathcal M,\ \Sigma\in\mathcal S} f_{\mu,\Sigma}(\sigma),\qquad \sigma>0,$$
holds, and when $\mathcal M$ and $\mathcal S$ are convex the equality
$$f_{\text{rob}}(\sigma) = \inf_{\mu\in\mathcal M,\ \Sigma\in\mathcal S} f_{\mu,\Sigma}(\sigma),\qquad \sigma>0$$
holds. This result has an implication for the sampling-based approach: if one uniformly samples pairs $(\mu^{(i)},\Sigma^{(i)})$ from $\mathcal U$ and computes the corresponding efficient frontiers $f_{\mu^{(i)},\Sigma^{(i)}}$, then in the convex case, as the number of samples grows, the infimum of the sampled frontiers converges to the robust frontier; in the non-convex case the infimum may not provide a good approximation, even with many samples [KimBoyd2007].

As with the nominal analysis, the robust frontier can be computed through maximization of the worst-case Sharpe ratio. The Sharpe ratio of a portfolio with respect to a hypothetical risk-free return $\bar r$ is $S_{\bar r}(w,\mu,\Sigma) = (w^T\mu - \bar r)/\sqrt{w^T\Sigma w}$, a notion linked to Roy's safety-first approach to portfolio selection [Roy1952]. Its worst-case value is $S_{\text{wc}}(w,\bar r) = \inf_{\mu\in\mathcal M,\ \Sigma\in\mathcal S} S_{\bar r}(w,\mu,\Sigma)$, and the problem of maximizing it,
$$\max\ \inf_{\mu\in\mathcal M,\ \Sigma\in\mathcal S} S_{\bar r}(w,\mu,\Sigma) \quad\text{s.t.}\quad w\in\mathcal W, \tag{13}$$
is called the worst-case Sharpe ratio maximization problem; when it admits a solution, it is unique. As the hypothetical risk-free return $\bar r$ varies, the worst-case risk-return pair of the solution of $(13)$ traces out the robust efficient frontier, which can therefore be constructed as the trajectory of such solutions [KimBoyd2007].

## The Conic Formulation and Convex Sets

The computational tractability of robust analysis is obtained when the sets $\mathcal M$ and $\mathcal S$ are convex. In that case problem $(13)$ can be solved efficiently by means of a minimax result for the Sharpe ratio, without structural assumptions beyond convexity [KimBoyd2007]. Kim and Boyd show that the worst-case market price of risk problem is equivalent to the convex problem
$$\min\ (\mu - \bar r\mathbf 1 + \lambda)^T \Sigma^{-1} (\mu - \bar r\mathbf 1 + \lambda) \quad\text{s.t.}\quad \mu\in\mathcal M,\ \Sigma\in\mathcal S,\ \lambda\in\mathcal W^{\oplus}, \tag{21}$$
with variables $\mu\in\mathbb R^n$, $\Sigma = \Sigma^T\in\mathbb R^{n\times n}$, and $\lambda\in\mathbb R^n$, where $\mathcal W^{\oplus}$ is the positive dual cone of $\mathcal W$. The objective function and the constraints are convex, and the problem always admits a solution $(\mu^*,\Sigma^*,\lambda^*)$, which is a least-favorable model, that is, solves the worst-case market price of risk problem. Problem $(13)$ admits a solution if and only if $\mathbf 1^T\big(\Sigma^{*-1}(\mu^*-\bar r\mathbf 1+\lambda^*)\big) > 0$, and in that case the least-favorable model $(\mu^*,\Sigma^*)$ has as its tangency portfolio
$$w^* = \frac{1}{\mathbf 1^T\Sigma^{*-1}(\mu^*-\bar r\mathbf 1+\lambda^*)}\,\Sigma^{*-1}(\mu^*-\bar r\mathbf 1+\lambda^*), \tag{22}$$
which is the unique solution of $(13)$ [KimBoyd2007].

It is in ellipsoidal uncertainty about expected returns that the second-order cone constraint reappears, for the same reason already seen. If $\mathcal M$ is an ellipsoid $\mathcal M = \{\bar\mu + Pu \mid \lVert u\rVert\le 1\}$, where the matrix $P$ determines its shape, by Cauchy-Schwarz the worst-case return is
$$\inf_{\mu\in\mathcal M} w^T(\mu - \bar r\mathbf 1) = w^T(\bar\mu - \bar r\mathbf 1) - \lVert Pw\rVert.$$
The term $-\lVert Pw\rVert$ is the cost that uncertainty about expected returns imposes on the worst-case return, and its presence makes the formulation a second-order cone program (SOCP). When the set $\mathcal M$ is instead a polyhedron $\mathcal M = \{\mu \mid A\mu\le b\}$, the equivalence between the formulations is established via the Lagrangian dual of the linear program $\min\{w^T\mu\mid A\mu\le b\}$, whose dual in standard form is $\max\{b^T\lambda \mid A^T\lambda + w = 0,\ \lambda\ge 0\}$; by strong duality the two formulations coincide [KimBoyd2007]. In general, when the worst-case risk constraint is representable by linear matrix inequalities, the robust problem is a semidefinite program (SDP), and when it is compatible with second-order cone programming it is an SOCP. Several robust selection problems with a structurally uncertain factor covariance model, an ellipsoidal model on the mean vector, and a polyhedral constraint set had already been formulated as SOCP [GoldfarbIyengar2003], and the results of Kim and Boyd show that they compute robust MV efficient portfolios.

This conic structure extends to other selection problems, which, once the robust frontier has been computed, reduce to simple one-dimensional searches over the set of robust MV efficient portfolios [KimBoyd2007]. Value-at-Risk is $V(w,\mu,\Sigma) = \kappa\sqrt{w^T\Sigma w} - w^T\mu$, with $\kappa>0$ a risk factor depending on the assumptions about the distribution: $\kappa = \Phi^{-1}(\epsilon)$ for the Gaussian case, and $\kappa = \sqrt{(1-\epsilon)/\epsilon}$ from the Chebyshev bound when only the first two moments are known. Its worst-case value is $V_{\text{wc}}(w) = \kappa\,\sigma_{\text{wc}}(w) - r_{\text{wc}}(w)$, and the minimization of worst-case VaR had been studied as a conic problem [ElGhaouiOksOustry2003]. Similarly, the maximization of worst-case expected quadratic utility has as its objective $\inf_{\mu\in\mathcal M,\ \Sigma\in\mathcal S}\big(w^T\mu - \tfrac{\gamma}{2}w^T\Sigma w\big) = r_{\text{wc}}(w) - \tfrac{\gamma}{2}(\sigma_{\text{wc}}(w))^2$, with $\gamma>0$ linked to risk aversion.

## Robustness Versus the Fragility of Mean-Variance Weights

The numerical comparison between the nominal frontier and the robust frontier closes the direct link between the two parts of the chapter. Kim and Boyd consider $8$ risky assets in the long-only case, with allocation set $\mathcal W = \{w\in\mathbb R^8 \mid w\ge 0,\ \mathbf 1^T w = 1\}$, nominal returns $\bar\mu$, nominal volatilities $\bar\sigma$, nominal correlation matrix $\bar\Omega$, and nominal covariance $\bar\Sigma = \operatorname{diag}(\bar\sigma)\,\bar\Omega\,\operatorname{diag}(\bar\sigma)$. The uncertainty model on expected returns combines a box and an aggregate constraint,
$$\mathcal M = \{\mu \mid |\mathbf 1^T\mu - \mathbf 1^T\bar\mu|\le 0{,}1\,|\mathbf 1^T\bar\mu|,\ |\mu_i - \bar\mu_i|\le 0{,}2\,|\bar\mu_i|,\ i=1,\dots,8\},$$
where the variation of each expected return is at most $20\%$ and that of the equally weighted portfolio's return is at most $10\%$; the covariance model combines an element-wise box and a Frobenius-norm constraint,
$$\mathcal S = \big\{\Sigma = \Sigma^T \mid \Sigma\ge 0,\ \lVert\Sigma - \bar\Sigma\rVert_F \le 0{,}1\,\lVert\bar\Sigma\rVert_F,\ |\Sigma_{ij}/\bar\Sigma_{ij} - 1|\le 0{,}2,\ i,j=1,\dots,8\big\}.$$
The robust frontier is computed by solving, for each $\bar r$, problem $(21)$ with the constraints of $\mathcal M$ and $\mathcal S$ so specified, reformulated as an SDP via the Schur complement [KimBoyd2007].

The results show that, evaluated with the nominal model, robust MV efficient portfolios perform slightly worse than nominal ones, but evaluated in the worst case the nominal portfolios perform worse than the robust frontier: robust optimal portfolios are less sensitive to variations in the parameters than nominal optimal portfolios. A detectable difference is that robust MV efficient portfolios are more diversified than nominal ones at the same risk level, and thus less prone to produce extreme outcomes; the robust minimum-variance portfolio is more diversified than the nominal one at the same performance level. As the maximum acceptable worst-case risk level increases, the discrepancy between the robust and nominal allocation tends to diminish, and beyond a threshold the two allocations coincide [KimBoyd2007].

This is the link that the chapter establishes. The fragility of mean-variance weights — their tendency to concentrate and to perform poorly under small variations in the estimated parameters, discussed in the chapter [[08 Errore di stima, outlier e shrinkage]] — is precisely what incorporating a model of parameter uncertainty and optimizing for the worst-case scenario systematically alleviates [KimBoyd2007]. Robustness does not add a distributional assumption, but replaces point values with an uncertainty set and requires that the solution hold for every realization of the data within it; when that set is ellipsoidal, tractability is preserved, because the problem remains a conic program solvable in polynomial time [BenTalNemirovski1999]. The construction of risk measures alternative to variance for the worst-case frontier, such as CVaR, is taken up in the chapter [[16 Ottimizzazione del CVaR - la formulazione di Rockafellar-Uryasev]].
